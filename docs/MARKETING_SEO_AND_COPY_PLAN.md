## 1) Copy Review + ข้อเสนอ Copy ใหม่

### 1.1 แหล่งข้อมูลที่ตรวจ

| ไฟล์ | บทบาท | หลักฐาน |
|---|---|---|
| `src/app/page.tsx` | React component หน้าแรก (client component) | อ่านเต็ม 639 บรรทัด |
| `src/lib/topa-content.ts` | `fallbackHomepageConfig` — ค่า default | อ่านเต็ม 256 บรรทัด |
| `apps/api/app/content/site/homepage.json` | ไฟล์ CMS จริงที่ `/site/homepage` เสิร์ฟ | `apps/api/app/routers/site.py:8-11` |
| `apps/api/app/services/homepage_content.py` | service โหลด/บันทึก/สำรอง CMS | อ่านเต็ม 141 บรรทัด |
| `src/app/admin/homepage/page.tsx` | หน้า admin แก้ CMS | อ่านเต็ม 208 บรรทัด |

> **หมายเหตุสำคัญ:** หน้าแรกเป็น `'use client'` → **SEO ได้ HTML จาก client render** ไม่ใช่ SSR metadata ที่ควบคุมได้ อีกทั้ง metadata ที่ประกาศไว้ใน `src/app/layout.tsx` เป็นของ **root layout** และจะถูกใช้กับทุกหน้า รวมถึง `/login` `/admin` — ซึ่งเป็นการทำลายคุณภาพ SEO ของหน้าอื่น

### 1.2 ประเมิน Headline / Subheadline

**Headline ปัจจุบัน (CMS จริง, `homepage.json`):**
```
เรียนเลขให้สนุก
เก่งขึ้นทุกวันกับ TOPA Math
```

**Subheadline ปัจจุบัน (CMS จริง):**
```
สำหรับน้อง ๆ ป.1-ป.6 ด้วย AI วิเคราะห์จุดอ่อน
เกมสนุก เควสท้าทาย และอันดับทั่วไทย
เสริมความมั่นใจ เก่งเลขได้จริงในทุกวัน!
```

#### สิ่งที่ทำได้ดี ✅
- สั้น อ่านเร็ว (8 คำในบรรทัดแรก)
- มีคำว่า "สนุก" ซึ่งตรงความต้องการของเด็ก
- ระบุช่วงชั้น "ป.1-ป.6" — ช่วยกรองกลุ่มผู้ฟัง
- มี 2 บรรทัดแรกเป็น "ผลลัพธ์" (เก่งขึ้น) — ที่ถูกต้อง

#### ปัญหาที่พบ 🔴

| ปัญหา | ผลกระทบ | หลักฐาน |
|---|---|---|
| **"ด้วย AI" นำหน้า** — AI เป็น buzzword ที่ผู้ปกครองไม่รู้ว่าได้อะไร | เพิ่มความสับสนแทนที่จะเพิ่มความน่าสนใจ | `homepage.json` hero.subheadline |
| **ไม่มี "Singapore Math" / "CPA" / "Bar Model" เลย** | ทิ้งความได้เปรียบเชิงเนื้อหาที่แข็งแรงที่สุดทิ้ง | grep `Singapore\|CPA\|Bar Model` ใน `src/` → ไม่พบในหน้าแรกเลย |
| **"อันดับทั่วไทย"** ทั้งที่อันดับจริงมี 1 แถว | เสี่ยงถูกฟ้อง + เสียความน่าเชื่อถือ | DB query → 1 row |
| **ไม่มี "หลักสูตรไทย + EP"** ใน hero | พ่อแม่ EP ต้องเจาะหาเอง ทั้งที่ระบบรองรับ (`program_type` = THP/EP/FREE) | `SELECT program_type, count(*)` → THP 76, EP 7, FREE 4 |
| **ไม่บอกว่า "ใช้ฟรี"** ว่าฟรีแค่ไหน | ผู้ปกครองกลัวโดนเก็บเงิน | มี free_test_limit ใน DB |
| **"เสริมความมั่นใจ...ในทุกวัน"** — คำเลิศ ไม่มีข้อพิสูจน์ | กลายเป็นคำโฆษณาเปล่า | ไม่มี data รองรับ |

**คะแนนความแข็งแรง (ประเมิน 1-5):**
- ดึงดูดความสนใจเด็ก: **3/5** ✅ (สนุก, สีสัน, มาสคอต)
- ดึงดูดความสนใจผู้ปกครอง: **2/5** 🔴 (ไม่มีหลักฐาน, ไม่มีวิธีเรียน, ไม่บอกราคา/ฟรี)
- ชัดเจนว่าใช้อะไร/ได้อะไร: **2/5** 🔴 (ไม่บอกวิธีสอน)
- เข้าใจใน 3 วินาที: **4/5** ✅

### 2.3 หลักการ "อย่าหลอกผู้ใช้" 5 ข้อ (นำไปทำเป็น checklist ก่อน ship)

1. **ตัวเลขทุกตัวต้อง trace ได้** — ถ้าไม่รู้ว่ามาจาก query ไหน ห้ามแสดง
2. **ถ้ายังไม่มีข้อมูลจริง ให้ซ่อนดีกว่าโชว์ตัวอย่าง** — หน้าแรกที่โล่งจะดูดีกว่าหน้าแรกที่โกหก
3. **รีวิวต้องมี consent** — เก็บ `consent_at` + เป็นตารางแยก ไม่ฝังใน CMS JSON
4. **อย่าสร้างดาวปลอม** — ถ้ามีรีวิวจริง 5 ดาว ให้แสดง 5 ดาว ถ้ามี 4.2 ก็แสดง 4.2
5. **ใส่ "ข้อมูล ณ วันที่ X"** — ป้องกันตัวเลขที่เปลี่ยนแปลงแล้วผิด

## 3) SEO Technical Audit (ตรวจจากโค้ดจริง)

### 3.1 🔴 P0 — Production ยังไม่มี SEO เลย

**หลักฐานจาก production จริง (2026-11-08):**
```bash
$ curl -sI https://topamath.com/
HTTP/1.1 200 OK
Content-Type: text/plain;charset=UTF-8
Server: cloudflare

$ curl -s https://topamath.com/robots.txt
Hello Topa Math!

$ curl -s https://topamath.com/sitemap.xml
Hello Topa Math!

$ curl -s https://topamath.com/pricing
Hello Topa Math!
```

> **การค้นพบสำคัญ:** string `Hello Topa Math!` **ไม่มีอยู่ในรีโปเลย** (ค้นด้วย `search_files` แบบ content search → `total_count: 0`) → ตัว Worker ที่ deploy อยู่เป็น **stub ที่ไม่ได้อยู่ในซอร์สโค้ด** นี่คือความเสี่ยงสูงสุด: ถ้ามีคน deploy ครั้งถัดไปโดยไม่ได้ build จริง หน้าเว็บทั้งเว็บจะหายไป

**`wrangler.toml`** ระบุ `main = ".open-next/worker.js"` และ `[build] command = "npm run cf:build"` → ต้องรัน build จริงก่อน deploy และ verify ว่า `.open-next/worker.js` ถูก build จาก commit ล่าสุด

**ผลกระทบ:** Googlebot จะเห็น `text/plain` ทุกหน้า → ไม่มีอันดับ, ไม่มี rich snippet, Facebook/TikTok share ก็ไม่มี preview

## 6) Checklist ก่อน Publish (ต้องทำทุกครั้ง)

- [ ] ตัวเลขทุกตัวในโพสต์ **trace กลับไปได้** — สคริปต์ `SELECT ...` หรือไฟล์นับเนื้อหา
- [ ] ถ้าใช้ตัวเลขจาก DB → ใส่ **"(ข้อมูล ณ วันที่ ...)"**

- [ ] ลิงก์ CTA ทำงานจริงและไปถึงปลายทางที่ถูกต้อง

- [ ] Mobile-first — ตรวจว่าอ่านออกบนมือถือก่อนโพสต์
