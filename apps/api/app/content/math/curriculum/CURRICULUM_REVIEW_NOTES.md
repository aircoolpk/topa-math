## 2. ช่องว่างที่พบ (Identified Gaps)

### Gap 1: เนื้อหาที่ยังไม่ครอบคลุม
รายการหัวข้อที่อาจต้องเพิ่มเติม:

| หัวข้อ | ชั้น | หมายเหตุ |
|--------|------|---------|
| การชั่งน้ำหนักมาตรฐาน (กก./ก.) | ป.2–3 | อาจต้องเพิ่มใน Measurement |
| การอ่านเวลาแบบ 24 ชั่วโมง | ป.3–4 | ยังไม่ระบุชัดเจน |
| การคำนวณเงินทอนซับซ้อน | ป.2–3 | มีแต่ระดับพื้นฐาน |
| กราฟเส้น (Line Graph) | ป.4–5 | มีแต่ Bar Graph |
| ความน่าจะเป็น (Probability) | ป.5–6 | มีเพียงเบื้องต้น อาจต้องขยาย |
| การแก้สมการสองตัวแปร | ป.6+ | เกินขอบเขต ป.6 แต่อาจเตรียมไว้ |
| บทประยุกต์ (Applications) | ป.4–6 | ยังไม่ครอบคลุม เช่น ดอกเบี้ย ส่วนลด |
| การวัดอุณหภูมิ (องศาเซลเซียส) | ป.2–3 | ไม่ระบุในหลักสูตร |

### Gap 2: ระดับความยาก (Difficulty Calibration)
- ยังไม่มีการระบุระดับ Bloom's Taxonomy ที่เหมาะสมต่อแต่ละชั้น
- ความยากของโจทย์ในแต่ละหัวข้อยังไม่มีการ calibrate กับข้อสอบจริง

### Gap 3: ความต่อเนื่องของ Model
- Bar Model ควรมีลำดับการสอนที่ชัดเจนขึ้นตลอดทั้ง 6 ปี
- Area Model สำหรับเศษส่วน (ป.5) ควรเชื่อมจาก Area Model สำหรับการคูณ (ป.3–4)

### Gap 4: การเชื่อมกับข้อสอบจริง
- ไม่มีการ map กับ Blueprint ข้อสอบ สพฐ. ที่แท้จริง
- ไม่มีการระบุขอบเขตข้อสอบ O-NET ป.6

### Gap 5: Individualized/Pacing
- ไม่มีตาราง Pacing Guide ที่แน่นอน
- ไม่มีระบบสำหรับนักเรียนที่เรียนเร็ว/ช้า

## 4. ลำดับการสอนที่แนะนำ (Teaching Sequence)

```
ป.1: นับ → Number Bond → บวกลบ 10 → บวกลบ 20 → วัด → เวลา/เงิน → รูปร่าง
ป.2: Place Value 1000 → บวกลบสองหลัก → สูตรคูณแม่ → วัด → เวลา/เงิน
ป.3: คูณหาร → เศษส่วน → โจทย์หลายขั้น → พื้นที่ → วัด → กราฟ
ป.4: จำนวนใหญ่ → คูณหารยาว → ทศนิยม → เศษส่วน → มุม → สมมาตร
ป.5: ล้าน/ทศนิยม → คูณหารเศษส่วน → ร้อยละ → อัตราส่วน → ปริมาตร
ป.6: สมการ → สัดส่วน/ร้อยละ → วงกลม → พื้นที่/ปริมาตร → สถิติ → เตรียมสอบ
```

**หมายเหตุ:** ก่อนขึ้นหัวข้อใหม่ที่ต้องใช้พื้นฐานเดิม ต้องทำ Diagnostic Test ก่อนเสมอ

## 5. ข้อเสนอแนะสำหรับการพัฒนาต่อ

### ระยะสั้น (1–2 เดือน)
1. สร้าง Quiz เพิ่มเติมสำหรับหัวข้อที่ยังไม่มี (ดูตารางข้างบน)
2. แก้ไข Quiz ที่มีปัญหา (g2_subtract_two_digit, g2_money_change, encoding files)
3. เพิ่มบทเรียน (Lessons) ตาม topic_map

### ระยะกลาง (3–6 เดือน)
1. สร้าง Quest files สำหรับทุกหน่วย
2. สร้าง Diagnostic Test ก่อนทุกหน่วย
3. สร้าง Adaptive Practice sets
4. ตรวจสอบ alignment กับ สพฐ. อย่างเป็นทางการ

### ระยะยาว (6–12 เดือน)
1. ขอ expert review จาก IPST/สสวท
2. ทดลองใช้ในห้องเรียนจริง
3. Calibrate ความยากกับข้อสอบจริง O-NET/สสวท
4. สร้าง Teacher Guide สำหรับทุกหน่วย
