# 🍕 การบวกและการลบเศษส่วนที่มีตัวส่วนเท่ากัน

> เชื่อมกับชีวิตประจำวัน: สมมติน้องกับเพื่อนกินพิซซ่าร่วมกัน 🍕 วันนี้เราจะเรียนว่าทำยังไงให้รู้ว่า **กินไปกี่ชิ้น** และ **เหลือกี่ชิ้น** ทั้งที่พิซซ่าถูกหั่นเป็นชิ้นเท่ากัน — แบบที่วิธีคิดเหมือนกันเป๊ะ! 🍕➡️➕

⏱ **ประมาณ 15 นาที**

---

## 🎯 เมื่อเรียนจบบทนี้ น้องๆ จะสามารถ...

- บวกเศษส่วนสองจำนวนที่มีตัวส่วนเท่ากันได้อย่างถูกต้อง
- ลบเศษส่วนสองจำนวนที่มีตัวส่วนเท่ากันได้อย่างถูกต้อง
- อธิบายได้ว่าทำไม "ตัวส่วนเท่ากัน" ถึงบวกหรือลบกันได้เลย

---

## 1. 🍕 เริ่มจากของจริงก่อน (Concrete)

ลองนึกภาพตามนะคะ

พี่สอนหั่นพิซซ่าให้น้องอยู่ **1 ถาด** ขนาดเท่ากัน แล้วหั่นออกมาให้เป็น **8 ชิ้นเท่าๆ กัน** ทุกชิ้นเท่ากันหมดเลยนะคะ

ตอนนี้น้องกินไปแล้ว **3 ชิ้น**

> ❓ **ถามน้องๆ:** กินไปกี่ "ส่วน" แล้ว? แล้วเหลือพิซซ่ากี่ชิ้น?

น้องๆ จะตอบว่า **กินไป 3 ส่วน เหลือ 5 ชิ้น**

พี่จะอธิบายต่อให้นะคะ:

- พิซซ่าทั้งถาด = **1 ทั้งหมด** ซึ่งถูกหั่นเป็น **8 ส่วนเท่ากัน**
- กินไป 3 ชิ้น → เราเขียนเป็นเศษส่วนได้ว่า **3/8**
- ตัวเศษ (3) = กินไปกี่ส่วน · ตัวส่วน (8) = ถูกหั่นทั้งหมดกี่ส่วน

### 📊 ตารางช่วยจำ: สัญลักษณ์กับของจริง

| สัญลักษณ์ | อ่านว่า | ของจริง |
|---|---|---|
| 1/8 | หนึ่งส่วนจากแปดส่วน | พิซซ่า 1 ชิ้น จากทั้งถาดที่หั่น 8 ชิ้น |
| 3/8 | สามส่วนจากแปดส่วน | พิซซ่า 3 ชิ้น |
| 5/8 | ห้าส่วนจากแปดส่วน | พิซซ่า 5 ชิ้น |

> 💡 **จำสังเกต:** ตัวส่วน (8) บอกว่า "ชิ้นหนึ่งใช้เวลาเท่าไร" — ทุกชิ้นเท่ากันหมด จึงเทียบกันได้ตรงๆ

## 2. 🖼️ วาดเป็นภาพ (Pictorial) — แถบ Bar Model

การเรียนเศษส่วนให้เข้าใจจริงๆ หลักสำคัญที่สุดคือ **วาดเป็นแถบ** นะคะ

สมมติน้องมีพิซซ่าอีกถาด หั่นเป็น **8 ชิ้นเท่ากัน** แล้วเพื่อนกินไป **2 ชิ้น**

```
ก่อนกิน — ทั้งถาด 8 ชิ้น = 8/8
🟦🟦🟦🟦🟦🟦🟦🟦
 1  2  3  4  5  6  7  8

กินไป — 2 ชิ้น = 2/8
🟦🟦⬜⬜⬜⬜⬜⬜
 1  2  3  4  5  6  7  8

เหลือ — 6 ชิ้น = 6/8
🟦🟦🟦🟦🟦🟦⬜⬜
 1  2  3  4  5  6  7  8
```

> 🔑 **นี่คือหัวใจสำคัญของบทนี้เลยนะ!** ขีดแถบทั้งแถว = เต็ม 8 ส่วน = 8/8
> ตัวส่วน (8) เหมือนกันเป๊ะทั้งสองข้าง → **เอามาลบกันได้เลย** ไม่ต้องทำอะไรยากๆ

### 📊 ตารางเทียบ: ตัวส่วนเท่ากัน vs ตัวส่วนไม่เท่ากัน

| | ตัวส่วนเท่ากัน ✅ | ตัวส่วนไม่เท่ากัน ❌ |
|---|---|---|
| ตัวอย่าง | 3/8 + 2/8 | 1/2 + 1/3 |
| ทำไม | ชิ้นเท่ากัน จึงรวมกันตรงๆ | ชิ้นไม่เท่ากัน ต้องแปลงก่อน |
| วิธีทำ | บวกเฉพาะตัวเศษ: 3+2 = **5/8** | ต้องหาตัวส่วนร่วมก่อน (ยากขึ้น) |
| ภาพ | 🟦🟦🟦⬜⬜⬜⬜⬜ | ❌ หั่นคนละขนาด เทียบกันไม่ได้ |

> 📌 **จำไว้เลย:** ถ้าตัวส่วนเท่ากัน → **บวก/ลบเฉพาะตัวเศษ** เอ็วจัง! ⚡

## 3. ➕ การบวกเศษส่วนที่มีตัวส่วนเท่ากัน

### 3.1 กฎที่ใช้เลย

```
ตัวส่วนเท่ากัน  →  คงตัวส่วนไว้เหมือนเดิม
             →  บวกเฉพาะตัวเศษ
```

### 3.2 ตัวอย่างที่ 1 — การบวก

> **โจทย์:** น้องกินพิซซ่าไป **3/8** ของถาด แล้วเพื่อนกินไปอีก **2/8** ถาดนี้กินไปรวมกันกี่ส่วน?

**วิธีคิดแบบ Bar Model:**
```
🟦🟦🟦⬜⬜⬜⬜⬜   3/8  (น้อง)
🟦🟦⬜⬜⬜⬜⬜⬜   2/8  (เพื่อน)
─────────────────────
🟦🟦🟦🟦🟦⬜⬜⬜   5/8  (รวมกัน)
```

**เขียนสัญลักษณ์:**
```
   3     2
 ─── + ─── = 5
   8     8     8
```

> ✅ **คำตอบ: 5/8**

### 3.3 ตัวอย่างที่ 2 — การลบ

> **โจทย์:** น้องมีพิซซ่า **7/8** ของถาด แล้วกินไป **2/8** เหลือพิซซ่ากี่ส่วน?

**วิธีคิดแบบ Bar Model:**
```
🟦🟦🟦🟦🟦🟦🟦⬜   7/8  (มีอยู่)
🟦🟦⬜⬜⬜⬜⬜⬜   2/8  (กินไป)
────────────────────
🟦🟦🟦🟦🟦⬜⬜⬜   5/8  (เหลือ)
```

**เขียนสัญลักษณ์:**
```
   7     2
 ─── - ─── = 5
   8     8     8
```

> ✅ **คำตอบ: 5/8**

### 3.4 ตารางสรุปวิธีทำ

| โจทย์ | ขั้นตอน | คำตอบ |
|---|---|---|
| 3/8 + 2/8 | ตัวส่วนเท่ากัน → บวกตัวเศษ: 3+2 | **5/8** |
| 7/8 − 2/8 | ตัวส่วนเท่ากัน → ลบตัวเศษ: 7−2 | **5/8** |
| 1/5 + 3/5 | ตัวส่วนเท่ากัน → บวกตัวเศษ: 1+3 | **4/5** |
| 6/9 − 4/9 | ตัวส่วนเท่ากัน → ลบตัวเศษ: 6−4 | **2/9** |

## 💡 ลองคิดดูสิ

> **โจทย์:** คุณแม่หั่นขนมปังไปตามร้านเบเกอรี่ **10 ชิ้นเท่ากัน** พี่ (ผู้สอน) กินไป **3 ชิ้น** และน้องกินไป **5 ชิ้น**
>
> **ถาม:** ทั้งคู่กินไปรวมกันกี่ส่วนของขนมปังทั้งสิบชิ้น? แล้วเหลือขนมปังกี่ชิ้น?

<details>
<summary>👀 ดูเฉลย</summary>

**เขียนเป็นเศษส่วนก่อน:**

พี่ (ผู้สอน) กิน 3 ชิ้น → 3/10
น้องกิน 5 ชิ้น → 5/10

**ตัวส่วนเท่ากัน (ทั้งคู่เป็น 10) → บวกเฉพาะตัวเศษ!**

```
   3     5
 ─── + ─── = 8
  10    10    10
```

**กินไปรวมกัน = 8/10 ของขนมปัง**

**เหลือ:**
```
  10     8
 ─── - ─── = 2
  10    10    10
```

> ✅ **กินไปรวมกัน 8/10 ส่วน และเหลือขนมปัง 2/10 ส่วน**
> (จากขนมปังทั้งหมด 10 ชิ้น เหลืออยู่ 2 ชิ้น 🍞)

</details>

## 📌 จำให้แม่น

> **1. ตัวส่วนเท่ากัน = ขนาดเท่ากัน = เอามาบวก/ลบกันได้เลย** ⚡
>
> **2. คงตัวส่วนไว้ เปลี่ยนแค่ตัวเศษ** — ตัวส่วนไม่เคยเปลี่ยน!
>
> **3. หั่นของให้เท่ากันก่อนเสมอ** — ถ้าหั่นไม่เท่ากัน ห้ามเอามาบวกกัน (จะข้อนี้เรียนในบทถัดไป!)
>
> **4. ข้อผิดที่พี่สอนเห็นบ่อยที่สุด:**
> - ❌ `3/8 + 2/8 = 5/16` (เอาตัวส่วนมาบวกกันด้วย — **ผิด!**)
> - ✅ `3/8 + 2/8 = 5/8` (คง 8 ไว้)
> - ❌ `7/8 − 2/8 = 5/16` (ผิด!)
> - ✅ `7/8 − 2/8 = 5/8` (คง 8 ไว้)
>
> **5. เคล็ดลับจำง่ายๆ:** ดูที่ **ตัวส่วน** ถ้าข้างล่างเหมือนกัน → บวก/ลบข้างบนอย่างเดียว! 👇

```
     3   +   2
    ───  +  ───  =  5/8
     8      8         ↑ ตัวส่วนเหมือนกัน = เอามาบวกกันได้
```

## 🎈 ท้ายบท

สิ่งที่น้องๆ เก่งวันนี้:
- ✅ รู้ว่าตัวส่วนเท่ากันทำให้บวก/ลบได้ง่าย
- ✅ บวกเฉพาะตัวเศษ ไม่ต้องแตะตัวส่วน
- ✅ ใช้ Bar Model ช่วยคิดได้แล้ว

**ครั้งหน้า** เราจะไปเรียนเรื่องที่ยากขึ้นนิดนึง — บวกเศษส่วนที่ **ตัวส่วนไม่เท่ากัน** 💪 แต่ไม่ต้องกลัวเลย เพราะมีวิธีเดียวกับที่น้องๆ เพิ่งเรียนมา!

> 🎯 **เรื่องถัดไป:** เศษส่วนที่มีตัวส่วนไม่เท่ากัน — เจอ 1/2 กับ 1/3 แล้วทำยังไง?

## 📚 คำศัพท์สำคัญ

| คำ | ความหมาย |
|---|---|
| เศษส่วน | ส่วนหนึ่งของของทั้งหมด มีตัวเศษ (บน) และตัวส่วน (ล่าง) |
| ตัวส่วน | บอกว่าของทั้งหมดถูกแบ่งเป็นกี่ส่วนเท่าๆ กัน |
| ตัวเศษ | บอกว่าเอากี่ส่วน |
