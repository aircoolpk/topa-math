## Issues Requiring Fixes

### Issue #1 — g1_money_basic mini_quiz answers (HIGH)
**File:** `grade_1/lessons/g1_money_basic.json`

mini_quiz `answer` fields do not match `correct_answer` or `explanation` in many variants.

Example (v01):
```
question: "เหรียญ 5 บาท 1 เหรียญ รวมเท่าไร?"
answer: "6"         ← numeric string
explanation: "5 บาท" ← text instead of answer
correct_answer: "6"
```
The answer should be `"5"` not `"6"`, and explanation should state the calculation.

Similar mismatches appear in all v01–v10 variants.

**Fix required:** Align `answer`, `correct_answer`, and `explanation` fields consistently.

---

### Issue #2 — g1_subtract_within_20 mini_quiz answers (HIGH)
**File:** `grade_1/lessons/g1_subtract_within_20.json`

Same mini_quiz answer mismatch pattern as g1_money_basic.

Example (v01):
```
question: "13 - 4 = ?"
answer: "9"
explanation: "คำตอบคือ 9"
correct_answer: "9"
```
Some variants show incorrect calculations in `explanation` fields (e.g., subtract questions producing answers that don't match the expression).

**Fix required:** Verify all mini_quiz answers against actual question math, correct explanation text.

### Issue #3 — Misfiled lesson file (LOW)

Grade 4 lesson found in grade_2/lessons directory. Should be in `grade_4/lessons/`.
